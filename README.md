# 前橋市デマンド交通データ可視化アプリ
# Maebashi City On-Demand Transport Data Visualization

## Webアプリ

以下のURLから、実際に動作するアプリを利用できます。

https://maebashi-demand-transport.streamlit.app/

## 1. プロジェクト概要

本プロジェクトは、群馬県前橋市のデマンド交通に関するオープンデータを活用し、GTFS-Flex形式の停留所情報と移動実績データを地図上で可視化するWebアプリです。

デマンド交通の停留所の分布や、利用者の乗車地点・降車地点の組み合わせを地図上に表示することで、データの全体像を直感的に把握できることを目指しています。

CSVなどのデータをそのまま表示するのではなく、地図や集計表を組み合わせ、交通データに詳しくない人でも利用状況を確認できるようにしています。

## 2. 主な機能

- GTFS-Flexデータに含まれる停留所の位置情報を地図上に表示
- 3つの路線グループごとに停留所を色分け
- 移動実績データから乗車地点・降車地点の組み合わせ（OD）を抽出
- ODの移動量に応じて線の太さを変え、地図上に表示
- 路線グループを選択して表示内容を切り替え
- 路線別の利用状況を集計表で表示
- 利用の多いODペアを一覧表示

## 3. 利用データ・出典

本アプリでは、公共交通オープンデータセンター（ODPT）で公開されている「前橋市 デマンド交通 / Maebashi City On-Demand Transport」の以下2種類のデータを利用しています。

**データ提供元**

株式会社未来シェア / Mirai Share

**利用データ**

- **GTFS-Flexによる乗降ポイントなど（GTFS-Flex形式）**

  デマンド交通の利用時間や乗降ポイントなど、交通サービスの運行条件・位置情報を示すデータです。

- **需要情報（CSV形式・ZIP圧縮）**

  デマンド交通の実際の利用実績を記録したデータです。乗車地点・降車地点の組み合わせなどを分析するために使用しています。

**データセット掲載元**

公共交通オープンデータセンター（ODPT）

前橋市 デマンド交通 / Maebashi City On-Demand Transport

https://ckan.odpt.org/ja/dataset/miraishare_maebashi_demand

データの提供元、ライセンス、利用条件、公開期間などについては、ODPT公式データセットページおよび各データの掲載情報をご確認ください。

なお、本データセットは「公共交通オープンデータチャレンジ2026」期間中の限定公開とされています。

## 4. データ取得方法

本アプリは、ODPTが提供するデータ取得用のURLを通じて、PythonのRequestsライブラリを使用し、GTFS-Flexデータおよび需要情報を取得します。

取得したZIPファイルは、Pythonのzipfileおよびio.BytesIOを使用してメモリー上で展開します。

データファイルをアプリのリポジトリに同梱する方式ではなく、アプリの実行時にデータ提供元から取得する方式を採用しています。

**本GitHubリポジトリには、元データのZIPファイルを収録していません。**

データの利用にあたっては、ODPT公式データセットページに掲載されているライセンスおよび利用条件に従ってください。公開状況や利用条件が変更される可能性があるため、利用時には最新の掲載情報をご確認ください。
