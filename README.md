# 前橋市 デマンド交通分析アプリ
# Maebashi City On-Demand Transport Analysis App

## 1. プロジェクト概要

本アプリは、公共交通オープンデータチャレンジ2026への応募を目的として開発中の、前橋市デマンド交通分析アプリです。

公共交通オープンデータセンター（ODPT）で公開されている前橋市のGTFS-Flexデータおよびデマンド交通の移動実績データを利用し、路線別の移動実績を集計するとともに、乗車地点から降車地点への移動を地図上で可視化します。

単なるデータ検索にとどまらず、デマンド交通の利用状況や移動の傾向を、地図と集計表を通じて直感的に把握できることを目指しています。

## 2. 主な機能

### データ取得・集計

- 公開データURLからZIPファイルを直接取得
- ZIPファイルをメモリー上で展開してデータを読み込み
- 乗車地点・降車地点の名称および位置情報を移動実績に結合
- 路線別の移動記録件数を集計
- 乗車地点・降車地点の組み合わせ別に移動実績を集計

### 集計表

- 全路線および個別路線の切り替え
- 路線別の移動記録件数の表示
- 乗車・降車の組み合わせ数の表示
- 移動実績上位20組の表示

### 地図による可視化

- 停留所を路線グループ別に色分けして表示
- 乗車地点から降車地点への移動を線で表示
- 移動記録件数に応じて移動線の太さを変更
- 停留所や移動線をクリックして詳細情報を表示
- 路線選択に応じて地図上の移動線を切り替え

## 3. 使用データと出典

### データセット

**前橋市 デマンド交通 / Maebashi City On-Demand Transport**

- 掲載サイト：公共交通オープンデータセンター（ODPT）
- 組織欄の記載：未来シェア / Mirai Share

データセット掲載ページ：

https://ckan.odpt.org/ja/dataset/miraishare_maebashi_demand

### 使用データ

- GTFS-Flex形式の交通データ
- デマンド交通の移動実績データ

### データ取得方法

ODPTが公開する以下のURLから、PythonのRequestsライブラリを使用してZIPファイルを直接取得します。

GTFS-Flexデータ：

https://api-public.odpt.org/api/v4/files/Demand/data/maebashi_gtfs.zip

移動実績データ：

https://api-public.odpt.org/api/v4/files/Demand/data/maebashi_demand.zip

取得したZIPファイルは、Pythonのzipfileおよびio.BytesIOを使用してメモリー上で展開します。

データファイルをローカルに事前ダウンロードする必要はありません。
